**This tool is designed to work with DEFRA emission factors for transport and compare with Google TPI emission factors**.
**For the Google TPI you must have a valid API key that needs to be entered into the Jupyter notebook otherwise it defaults to DEFRA**

The tool works for travel between two places or between multiple cities and one city, for example when comparing flights, trains etc. 
to and from a conference location. 

**NOTE: Google TPI is not as accurate as the DEFRA footprint - it doesn't account for aerosol impacts for example**
